# Bare Bones Texture Pack Plus

![visitors](https://visitor-badge.laobi.icu/badge?page_id=fankyfankz.barebones&left_text=Viewed&radius=0)

This project is a fork of the Bare Bones texture pack shared through the
[Bare Bones Discord Server](http://discord.gg/VD9rrF5).

This pack targets Minecraft Bedrock Edition 26.51+ and includes PBR and
ray-tracing support.
